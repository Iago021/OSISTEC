OSISTEC — PROTÓTIPO DE APLICATIVO EM HTML

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html no navegador.
3. O aplicativo funciona sem instalar dependências e sem internet.

ABAS DO APLICATIVO
- Plantões: oportunidades simuladas para médicos e profissionais de enfermagem.
- Buscar: aba principal para pesquisar sintomas, especialidades e unidades, além da pré-triagem demonstrativa.
- Farmácia: consulta simulada de estoque, preços e reserva temporária de medicamentos.

FUNCIONALIDADES
- Busca e filtros funcionais.
- Check-in demonstrativo.
- Pré-triagem demonstrativa, sem diagnóstico.
- Candidatura a plantões.
- Reserva temporária de medicamentos.
- Informações salvas localmente no navegador.
- Layout mobile-first e adaptável a telas maiores.
- Manifesto e service worker para funcionar como PWA quando hospedado em HTTPS ou servidor local.

IMPORTANTE
Este projeto é apenas um protótipo visual. Unidades, tempos, preços, estoques, vagas e reservas são fictícios. Nenhuma informação é enviada para hospitais, farmácias ou conselhos profissionais.
